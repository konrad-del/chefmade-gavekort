# Chefmade Gift Card

Static website for the Chefmade gift card, served at gavekort.chefmade.dk.

The buyer chooses a number of guests and a style (Casual, Gourmet, or Michelin Experience), or a custom amount (minimum 500 kr.). Payment is handled by a Stripe Payment Link. Gift cards never expire. Physical delivery includes free shipping.

This is a static site (HTML, CSS and JavaScript only). It does not use a server-side build.
